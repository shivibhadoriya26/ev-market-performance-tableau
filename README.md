# EV Market Performance Dashboard

An interactive Tableau dashboard analyzing Electric Vehicle (EV) market trends, adoption rates, manufacturer performance, and regional sales distribution.

## Project Overview
This project explores global/regional electric vehicle adoption data to uncover key insights regarding market growth, charging infrastructure distribution, and top-performing EV models and manufacturers.

## Features & Insights
* **Market Growth Trends:** Year-over-year growth in EV registrations and sales.
* **Manufacturer Comparison:** Breakdown of market share among leading EV brands.
* **Geographical Distribution:** Regional analysis highlighting leading states/countries in EV adoption.
* **Vehicle Segmentation:** Insights into Battery Electric Vehicles (BEVs) vs. Plug-in Hybrid Electric Vehicles (PHEVs).
